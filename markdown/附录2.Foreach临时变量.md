## 1.1 使用临时变量

Foreach的临时变量一般以#+变量名开头，如a->{};则以#a开头，通过#后面的参数访问临时变量。

```
file = getFile(".\test\");
println("file: ",file);

files = listFiles(file);
println("listFiles: ",files);

files -> {
    println("#tFile: ",#files," ",#files#name);//#t是转义字符，表示\t
};
```
## 内部变量

#foreach 访问当前变量（如果是集合则是当前迭代中的变量）

### Map
#k #v分别为key和value

### Collection
#foreach 访问当前迭代中的变量

### File
#path 文件路径
#name 文件名称

### CommandResult
#out 标准输出流 返回List
#err 标准错误流 返回List
#exitcode 退出码
