## 函数调用
ABatch 以半角分号区分语句，且认为代码块是一系列可有序执行的语句。

你可以通过函数名称加小括号来调用函数，可以自定义也可以调用标准库函数

[格式化输出](./batch/格式化输出.ab)
```ab
a = "hello";
print("Hello");       // 不换行输出
println("World");     // 带换行输出
printf("格式 %s", a); // 格式化输出
```

## 赋值和注释

由于以分号区分语句，所以你可以像Java那样子把所有语句写为一行也不会报错。

ABatch 的字符串通过半径双引号括起来，在解释器执行初期就会把所有字符串作为字面量存储起来。

ABatch 的注释以"//"开头，后面的字符都不会被解释器解释。

赋值与其他语言相似，并且 ABatch 支持连锁赋值，如下：（需要注意的是：每次复制都会执行一次等号最右侧的内容）
```
a = "str";
b = c = GetTimeMillis(); //当前时间(ms为单位)
```

## Foreach

ABatch 的Foreach和Java的lambda很类似，通过"->"作为关键字执行Foreach。

Foreach箭头前的可以是List、Map、File等变量，这都会自动在后面创建临时变量。

如下，这是一个简单的程序，实现的输出一个目录下的全部文件的功能：

```
file = getFile(".\test\");
println("file: ",file);

files = listFiles(file);
println("listFiles: ",files);

files -> {
    println("#tFile: ",#files," ",#files#name);//#t是转义字符，表示\t
};
```
