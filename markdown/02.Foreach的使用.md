# 1. 引言

Foreach是JavaStream的一种特色，这种语法使得程序编写更为简单，所以这将会作为 ABatch 的一种特色。
## 1.1 使用Foreach

ABatch 的Foreach和Java的lambda很类似，通过"->"作为关键字执行Foreach。

Foreach箭头前的可以是List、Map、File等变量，这都会自动在后面创建临时变量。

如下，这是一个简单的程序，实现的输出一个目录下的全部文件的功能：

```
file = getFile(".\test\");
println("file: ",file);

files = listFiles(file);
println("listFiles: ",files);

files -> {
    println("#tFile: ",#files," ",#files#name);//#t是转义字符，表示\t
};
```
