# 1. 引言

Batch是Windows下的一门脚本语言，可以直接的执行命令并且唤起其他应用程序。但是对于更加需要细致控制的命令和更简易的文件操作，AxolotlBatch(ABatch)将会是你的不二之选。

## 1.1 为什么使用 ABatch

ABatch 支持更好的变量控制，支持简易的Foreach，支持调用调用开发者提供的函数。（并且未来可以支持反射以调用Java原生的方法和字段）

ABatch 是开源的，所以你可以轻松的构建一些简易的命令，或者接入你的程序允许用户更高的自定义程序。
你可以添加自己的函数和语法，使得使用更方便。

## 1.2 ABatch 语法简介
ABatch 以半角分号区分语句，且认为代码块是一系列可有序执行的语句。如：

```
println("hello");
print("hello ","world");
```

由于以分号区分语句，所以你可以像Java那样子把所有语句写为一行也不会报错。

ABatch 的字符串通过半径双引号括起来，在解释器执行初期就会把所有字符串作为字面量存储起来。

ABatch 的注释以"//"开头，后面的字符都不会被解释器解释。

赋值与其他语言相似，并且 ABatch 支持连锁赋值，如下：（需要注意的是：每次复制都会执行一次等号最右侧的内容）
```
a = "str";
b = c = GetTimeMillis(); //当前时间(ms为单位)
```
