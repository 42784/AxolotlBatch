# 1. 引言

Batch是Windows下的一门脚本语言，可以直接的执行命令并且唤起其他应用程序。但是对于更加需要细致控制的命令和更简易的文件操作，AxolotlBatch(ABatch)将会是你的不二之选。

## 1.1 为什么使用 ABatch

ABatch 支持更好的变量控制，支持简易的Foreach，支持调用调用开发者提供的函数和自定义函数。（并且未来可以支持反射以调用Java原生的方法和字段）

ABatch 是开源的，所以你可以轻松的构建一些简易的命令，或者接入你的程序允许用户更高的自定义程序。
你可以添加自己的函数和语法，使得使用更方便。

支持的功能如下：
1. 变量连锁赋值，如a=b=c;
2. 用户自定义函数 def a(){};
3. 函数返回值和变量的检查 执行的时候需要求值时会检查有没有返回值和其是否正确
4. Foreach 可以直接访问部分对象内部变量 可以访问列表、Map、数组
5. 函数的嵌套执行
6. 通过函数进行复杂的数学计算和布尔运算
7. 拥有缓存表机制，可以执行更快
8. 等等...
